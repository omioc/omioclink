约定：

- 截图宽度建议 1600~2000px，单张压在 500 KB 以内（仓库里放大图会拖慢 clone）
- 桌面一律 **夜航** 主题；涉及手机界面的配图用手机默认的 **青竹** 主题
- 放置前先确认图里没有：真实服务器地址（左栏底部那张卡片第二行就是它）、账号昵称、真实房间名、聊天内容、个人头像
- 截图与收款码都可能带 EXIF（这两张收款码就带 `Software=Screenshot` 和截图时间戳）；介意的话另存一次再放进来
- 收款码换设备/换号后会失效，换码时直接覆盖同名文件即可
